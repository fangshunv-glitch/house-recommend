# Love & Forever

一个帮助两个人一起筛选、比较和记录婚房候选的小型网页工具。

当前版本以北京新房和二手房的社区筛选、房源导入、评分排序和看房备注为主。页面数据保存在浏览器本地，不会自动上传到服务器。

## 使用方式

### 直接打开

双击 `index.html`，或将它拖入浏览器即可使用。

### 本地静态服务器

如果浏览器对本地文件有限制，可以在项目目录运行任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 主要功能

- 复古模式和素净模式切换
- 可配置预算、通勤、户型、面积、房屋类型等筛选条件
- 单独导入小区数据，查看均价、挂牌量和基础筛选状态
- 导入具体房源数据，并按评分、价格和通勤条件筛选
- 支持新房和二手房
- 支持房源备注和看房记录
- 使用浏览器 `localStorage` 保存当前设备上的设置、导入记录和备注

## 导入数据

网页支持单条 JSON、JSON 数组，以及带 `items`、`communities`、`houses`、`records` 或 `data` 数组的 JSON 文件。

标准字段和示例请参阅 [数据对接格式.md](数据对接格式.md)。采集工具导出的数据可以先整理成该格式，再通过页面工具栏的“导入小区 / 房源 JSON”按钮导入。

导入数据仅保存在当前浏览器中。重复导入时，网页会根据稳定 ID、链接或组合字段更新已有记录，避免重复累积。

## 项目边界

本仓库只包含网页和数据接口说明，不包含：

- 房源采集器和浏览器扩展
- 真实房源数据、账号信息或登录凭据
- 设计参考文档
- 后端服务和数据库

当前项目是一个无需编译的静态前端原型，不提供 `.exe` 等桌面可执行程序。后续如果增加自动采集、定时任务、多人同步或云端存储，再考虑引入后端服务和独立部署方式。
